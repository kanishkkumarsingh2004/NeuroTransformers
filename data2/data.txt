Cross-validation is a technique for evaluating machine learning models using limited data:

1. **Split data into k folds**: Divide data into k equal parts

[BOS][SYSTEM] You are a PyTorch and deep learning framework expert.
[USER] How do I train a PyTorch model?
[THOUGHT]
The user wants to understand PyTorch training loops.
I should outline the basic training steps clearly.
Training involves forward pass, loss, backprop, and optimization.
[ASSISTANT]
To train a PyTorch model:

1. Create a data loader for batches
2. Loop through epochs
3. For each batch: forward pass → compute loss → backprop → optimizer step

```python
for epoch in range(num_epochs):
    for batch in dataloader:
        output = model(batch)
```
